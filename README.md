# Frontend Developer Roadmap

Hoja de ruta práctica para aprender desarrollo frontend, desde los fundamentos web hasta la construcción de componentes interactivos con JavaScript.

## Proyectos incluidos

| Proyecto | Qué se practica | Ruta |
|---|---|---|
| FAQ Accordion | Estructura HTML, estilos, animaciones y lógica de expansión exclusiva | [accordion](./javaScript-projects/accordion/) |
| Simple Tabs | Manipulación del DOM, eventos y gestión de paneles activos | [tabs](./javaScript-projects/tabs/) |

## Ruta de aprendizaje sugerida

1. **HTML:** semántica, formularios, accesibilidad y estructura de páginas.
2. **CSS:** selectores, box model, Flexbox, Grid, responsive design y animaciones.
3. **JavaScript:** variables, funciones, arrays, objetos, módulos y asincronía.
4. **DOM y eventos:** selección de elementos, listeners, estados y renderizado.
5. **Consumo de APIs:** HTTP, Fetch, JSON, loading states y manejo de errores.
6. **Frameworks:** componentes, routing, estado y pruebas.
7. **Calidad y publicación:** accesibilidad, rendimiento, testing y despliegue.

## Cómo ejecutar los ejercicios

Los proyectos actuales son páginas estáticas. No requieren Node.js ni un proceso de compilación:

1. Clona el repositorio.
2. Abre la carpeta del ejercicio.
3. Abre su archivo `index.html` en un navegador moderno.

Ejemplo:

```bash
git clone https://github.com/Serio120/roadmap-frontend-developer.git
cd roadmap-frontend-developer/javaScript-projects/accordion
```
